DUET CORE - TEMPLATES VERSIONADOS V1
=====================================

OBJETIVO DESTA ENTREGA
----------------------
Esta etapa adiciona a base funcional de Templates versionados ao DUET:

- Template possui identidade própria.
- Cada upload gera uma versão imutável.
- O primeiro upload cria a versão 1.
- Uma nova publicação cria automaticamente v2, v3, v4...
- Existe uma versão atual por Template.
- O formulário de criação de projeto passa a oferecer:
    1. Nova automação (workspace limpo)
    2. Usar Template
    3. Evoluir robô publicado
- Ao escolher Template, a versão atual é selecionada por padrão.
- Uma versão histórica também pode ser escolhida explicitamente.
- O ZIP é copiado/descompactado somente na criação do projeto.
- Atualizações futuras do Template NÃO modificam projetos já criados.
- O projeto guarda somente a proveniência do Template utilizado.

IMPORTANTE
----------
Esta entrega NÃO altera a execução dos Robots e NÃO modifica o Scheduler.
Também NÃO utiliza placeholders.

A tela administrativa "Administração > Templates" ainda precisa ser ligada
à navegação do frontend. Para essa próxima etapa serão necessários os arquivos
atuais App.tsx e Sidebar.tsx. O backend de Templates e a escolha do Template
na criação do projeto já ficam preparados nesta entrega.

FORMATO DO ZIP DO TEMPLATE
--------------------------
O Template deve ser um ZIP contendo o projeto-base.

Formato aceito A - arquivos diretamente na raiz:

main.py
requirements.txt
src\...
config\...

Formato aceito B - uma única pasta externa:

MeuTemplate\main.py
MeuTemplate\requirements.txt
MeuTemplate\src\...

Ao criar o projeto, a pasta externa única é removida e o conteúdo vira a raiz
do workspace.

O Template precisa conter main.py na raiz lógica.

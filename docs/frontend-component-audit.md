# Auditoria atômica do frontend

Atualizado em 27/09/2026. Os estados abaixo são independentes: **auditado** identifica o problema; **implementado** registra a origem corrigida; **aplicado** exige consumidores migrados; **validado** exige evidência executada. Uma família pode estar implementada sem estar totalmente propagada.

## Gates externos rastreados

1. Workflows autenticados contra o backend real exigem `DUET_TEST_ADMIN_PASSWORD`, indisponível no processo desta sessão; a ausência não foi contornada com credencial embutida.
2. Dados volumosos: carga prolongada de tabelas e logs deve ser medida antes de qualquer virtualização.
3. Validação assistiva: leitor de tela, zoom, teclado virtual e dispositivos reais continuam gate de aceitação; automação não substitui essa verificação humana.
4. Operações de publicação, execução, cancelamento e manipulação de segredos não foram disparadas sem autorização específica.

# Auditoria atômica do frontend

## Evidências desta rodada

- `npm run build`: aprovado com TypeScript estrito e `noUncheckedIndexedAccess`; 2.111 módulos transformados.
- `npm run lint`: zero erros e zero avisos; efeitos, dependências e Fast Refresh foram corrigidos na origem, sem relaxar regras.
- `npm run test:components`: três cenários aprovados (390 escuro, 1440 claro, 320 com movimento reduzido), sem overflow, botões sem nome, campos sem rótulo, alvo menor que 32 px ou erro de console; confirmação compartilhada contém e devolve foco em todos os cenários.
- `npm run test:visual`: 33 cenários aprovados em 320/390/768/1440, claro/escuro e movimento reduzido. Inclui vazios equivalentes de Executions/History/Schedules, persistência de filtros com voltar/avançar, explorador de Logs com pesquisa/filtro/pausa, formulário de pasta aberto, modal de agendamento, novo projeto e upload disponível na raiz; falha diante de busca local, vazio legado ou ícone decorativo de header.
- `python -m unittest discover -s tests -v` no ambiente virtual: 12 testes aprovados e três integrações PostgreSQL omitidas por proteção explícita; os lotes incluem contratos de Devices/Logs, sanitização de telemetria, lifecycle e a barreira estrutural contra exposição de exceção/corpo upstream em respostas HTTP.
- OpenAPI inspecionado localmente: listagem e criação de Agents referenciam schemas explícitos, incluindo união discriminada de sucesso/erro; o token do Agent permanece fora dos contratos públicos.
- Explorador de logs validado com dados sintéticos: pesquisa e filtro reduzem o conjunto corretamente, pausar interrompe polling, o estado fica anunciado e não há overflow, campo sem rótulo, alvo reduzido ou erro de console em 390 e 1440 pixels.
- Capturas revisadas incluem o catálogo e comentários, Robots, Development com criação aberta, modal de Schedules, Vault, Roles, Users, Logs e Studio em contextos representativos de desktop e mobile.
- `npm run test:workflow-ui`: não reexecutado nesta rodada porque `DUET_TEST_ADMIN_PASSWORD` não está disponível no processo atual. Evidência anterior permanece registrada em `frontend-reconstruction.md`, mas não foi tratada como validação nova.

## Gates externos rastreados

1. Workflows autenticados contra o backend real exigem `DUET_TEST_ADMIN_PASSWORD`, indisponível no processo desta sessão; a ausência não foi contornada com credencial embutida.
2. Dados volumosos: carga prolongada de tabelas e logs deve ser medida antes de qualquer virtualização.
3. Validação assistiva: leitor de tela, zoom, teclado virtual e dispositivos reais continuam gate de aceitação; automação não substitui essa verificação humana.
4. Operações de publicação, execução, cancelamento e manipulação de segredos não foram disparadas sem autorização específica.
